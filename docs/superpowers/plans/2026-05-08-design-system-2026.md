# Design System 2026 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate the Hub B2B frontend from a dark-first glassmorphic aesthetic to a light-first, indigo-primary, bento-grid design system consistent with the approved mockup (`mockups/design-system-2026.html`).

**Architecture:** All visual tokens live in `globals.css` and `layout.tsx`. Changing tokens in Task 1–2 cascades to 80% of the UI automatically. Tasks 3–6 fix the remaining hardcoded dark values and update the dashboard layout. Task 7 removes dead CSS. No business logic changes — all data fetching stays untouched.

**Tech Stack:** Next.js 16, React 19, Tailwind CSS v4, shadcn/ui, next-themes (new), Plus Jakarta Sans (new font), Lucide React.
